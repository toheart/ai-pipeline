# 测试分层决策引擎

测试分层设计的核心参考。为 qa-tester Agent 和 Orchestrator 的 qa-test 阶段提供测试策略指导。

## 三种工作模式

| 模式 | 触发时机 | 产出物 |
|---|---|---|
| **A：分层设计** | explore/propose 阶段产出测试方案 | 测试分层方案文档 |
| **B：编码指导** | implement 阶段传递给 implementer | 测试编码指导（可传递给 SubAgent） |
| **C：提交前检查** | qa-test 阶段做最终验收 | 结构化检查清单 |

## 实用 4 层金字塔

```
              E2E（Playwright / Cypress）
             少量核心用户路径
            ╱                ╲
         API 冒烟测试
        HTTP 级别，仅 P0（路由/中间件/参数绑定）
       ╱                        ╲
     皮下测试（Subcutaneous Test）
    Application Service 级别，大量业务场景
   ╱                                ╲
  单元测试（Domain 层 + 前端纯函数）
  纯逻辑，业务契约驱动断言
```

| 层 | 数量占比 | 覆盖目标 | 决策规则 |
|---|---|---|---|
| 单元测试 | 50-60% | Domain 层业务规则 + 前端纯函数 | 能用纯函数/方法测的都下沉到这里 |
| 皮下测试 | 25-35% | 业务编排、状态流转、跨域协调 | 需要真实依赖但不需要 HTTP 的场景 |
| API 冒烟 | 5-10% | 路由匹配、中间件、参数绑定 | 仅新增/修改 API 端点时补 |
| E2E | 5% | 核心用户路径端到端通畅 | 仅核心 Happy Path |

**皮下测试**是 ROI 最高的中间层——比 HTTP 集成测试快（无 HTTP 开销）、比单元测试真实（使用真实 DB）、比 E2E 稳定（不依赖 UI）。

## 分层决策树

```
1. 风险是否真实存在？
   └─ 否 → 不测
   └─ 是 ↓

2. 能用单元测试覆盖？
   └─ 能 → 单元测试（ROI 最优）
   └─ 不能 ↓

3. 能用 API / 集成测试覆盖？
   └─ 能 → API 或集成测试
   └─ 不能 ↓

4. 能用皮下测试覆盖？
   └─ 能 → 皮下测试
   └─ 不能 ↓

5. 必须 UI E2E？
   └─ 是 → UI E2E（最后手段）
```

## 3KU 原则

每个测试点必须通过三个检验：

1. **Useful（有效）**：测试点对应真实风险
2. **Ultimate（最优层）**：能下沉就下沉，选 ROI 最高的层
3. **Unique（不重复）**：不同层不重复覆盖同一件事

## 断言来源验证

为每个被测函数的断言标注来源，优先级由高到低：

| 来源层级 | 说明 | 可信度 |
|---|---|---|
| L1 业务契约 | 来自需求文档、用户故事、验收标准 | 高 |
| L2 API 契约 | 来自接口定义、OpenAPI、Proto | 高 |
| L3 共享常量 | 前后端共享的枚举、状态码 | 中 |
| L4 代码推导 | 仅从当前代码实现推断 | 低 |

规则：
- L1-L3 来源的断言直接写，它们是**业务防护网**
- L4 来源的断言在测试注释中标注 `// 断言来自代码推导，需业务确认`
- 如果一个函数所有断言均为 L4，先向用户确认业务意图再写测试

## 模式 C：提交前检查清单

```markdown
### 单元测试
- [ ] domain 层新增/修改的业务规则是否有对应单元测试
- [ ] 边界条件和异常路径是否覆盖
- [ ] Mock 是否与真实接口一致

### 皮下测试
- [ ] Application Service 的编排逻辑是否有皮下测试覆盖
- [ ] 跨域协调和状态流转是否验证

### API 冒烟
- [ ] 新增/修改的 API 端点是否有 P0 冒烟测试

### E2E 测试
- [ ] 是否影响核心用户路径（如果是，E2E 是否需要更新）

### 断言来源
- [ ] 每个断言是否标注了来源
- [ ] 无"复述代码"式断言
```

## 禁止行为

- 不要为了覆盖率而堆测试
- 不要在 UI 层验证业务计算逻辑
- 不要 Mock 需要验证真实集成的依赖
- 不要跳过测试数据策略设计
